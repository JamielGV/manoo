## Reddit r/ClaudeAI (inglés, más contexto — Reddit castiga el tono de venta)

**Título:** I built a plugin that gives Claude Code actual mouse/keyboard control (open source, free tier)

**Cuerpo:**
> Been using Claude Code a lot and kept hitting the same wall: it can tell
> me exactly what to click, but not actually click it. So I built Manoo —
> an MCP plugin that gives Claude screenshot + mouse/keyboard/scroll
> control on Linux.
>
> A few things I focused on since this touches your actual input devices:
> - It stops immediately if you touch your mouse/keyboard for real (global
>   input hook, not scoped to one window — safe by default).
> - Screen splits automatically so you always see what Claude's "thinking"
>   while it acts, instead of losing the chat behind the app it's driving.
> - Everything runs locally — no telemetry, no screen data leaving your
>   machine.
>
> Free tier is 25 actions/session, no signup needed to try it. Code's on
> GitHub: [LINK]
>
> Genuinely curious what people would use this for — happy to answer
> questions about how it works under the hood.

(Nota: en Reddit, entrar como "aquí está mi producto, cómprenlo" se
castiga. Este texto está pensado para leerse como alguien compartiendo
algo que construyó, no como un anuncio — eso es lo que mejor funciona ahí.)
