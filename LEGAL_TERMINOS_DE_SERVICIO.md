## 1. Qué es Manoo

Manoo es un plugin para Claude Code que da a Claude control del mouse, teclado y capacidad de tomar capturas de pantalla en el equipo donde se instala, para ejecutar acciones que el usuario le pida directamente sobre la interfaz gráfica.

## 2. Planes

- **Free:** funciones completas, limitadas a 25 acciones por sesión del servidor.
- **Pro:** acciones ilimitadas + registro de auditoría local de las acciones ejecutadas. Requiere una licencia activa emitida por Jamiel García Velázquez ("Corporación Jamiel").
